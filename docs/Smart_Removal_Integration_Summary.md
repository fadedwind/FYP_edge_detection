## 🚀 使用方法

### 启动项目

```bash
# 终端1：启动后端
python edge_detection_api.py

# 终端2：启动前端
cd vue-frontend
npm run dev
```

### 在浏览器中使用

1. 打开 http://localhost:5173
2. **点击左侧导航栏的"✂️ 智能抠图"按钮**
3. 选择抠图方法：
   - 🤖 **自动** - 推荐使用
   - ⭐ **rembg** - 效果最好（需要安装）
   - 🔍 **边缘辅助** - 使用项目边缘检测（PiDiNet）
   - ✂️ **GrabCut** - 传统方法
4. 上传图片
5. 点击"开始抠图"
6. 查看结果（棋盘格背景显示透明效果）
7. 下载PNG结果

## 🎯 与边缘检测的关系

### 边缘辅助方法

**核心优势**：直接使用项目的PiDiNet边缘检测算法

```
边缘检测流程：
原始图像 → PiDiNet边缘检测 → 边缘图 → 形态学处理 → 填充轮廓 → 生成Mask → 抠图结果
```

**特点**：
- 🔗 与项目边缘检测完美集成
- ⚡ 无需额外模型
- 🎯 利用现有PiDiNet功能
- 💡 展示边缘检测的实际应用

## 💡 使用技巧

### 选择合适的方法

| 场景 | 推荐方法 | 原因 |
|------|----------|------|
| 照片抠图（人物/宠物） | rembg | 训练过人像数据 |
| 游戏素材提取 | rembg | 对各种对象效果好 |
| 简单背景车辆 | **边缘辅助** | 项目集成，速度快 |
| 无网络/离线 | GrabCut | OpenCV内置 |
| 最佳质量 | rembg | 深度学习模型 |
| **展示边缘检测应用** | **边缘辅助** | **直接使用PiDiNet** |

### 工作流程示例

**场景：从截图中提取游戏角色**
1. 点击左侧"✂️ 智能抠图"
2. 选择方法：rembg
3. 上传游戏截图
4. 点击"开始抠图"
5. 下载透明背景PNG ✨

**场景：车辆提取（结合边缘检测）**
1. 使用YOLOv8检测车辆 🚗
2. 点击"✂️ 智能抠图"
3. 选择方法：边缘辅助（使用PiDiNet）
4. 上传车辆图片
5. 获得透明背景车辆图片
